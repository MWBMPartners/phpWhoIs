# WHOIS Lookup — Production

**Version:** 0.2.590
**Branch:** `main`
**Status:** Stable

## Overview

PHP-based domain WHOIS lookup tool.

## Features

- WHOIS lookup via system `whois` command
- Domain extraction using Public Suffix List
- Formatted and raw result views
- URL parameter support (`?domain=example.com`)
- Bootstrap 4 responsive layout

## Files

| File | Purpose |
|------|---------|
| `index.php` | Frontend — HTML, jQuery, AJAX |
| `lookup.php` | Backend — WHOIS lookup logic |
| `infoAppVer.php` | Application version metadata |
| `style.css` | Custom styles |
